# Artem Prokop

Single-page portfolio for [ExposedCat.github.io](https://ExposedCat.github.io).

GitHub repository previews load directly from GitHub's Open Graph image service so
repository statistics can refresh without a site update. GitHub controls image
caching, so changes may take time to appear. Saved WebP previews serve as fallbacks
if GitHub's images cannot load; app screenshots remain local assets.
